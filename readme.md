# Proyecto web informátivo para Gomería Bella Unión

Sitio web desarrollado para Gomería Bella Unión, ubicada en Colonia Valdense, Colonia, Uruguay.

## Contexto del proyecto

El proyecto surge a partir del análisis de las necesidades de una gomería local y de la importancia de contar con una presencia digital clara y profesional.

Se buscó desarrollar una página que permitiera a potenciales clientes conocer rápidamente los servicios ofrecidos, consultar horarios, encontrar la ubicación del negocio y acceder a diferentes medios de contacto.

A partir de este análisis se planteó una solución enfocada en:

- Mejorar la presencia digital del negocio.
- Facilitar el acceso a información importante.
- Presentar los servicios de forma clara y visual.
- Facilitar el contacto con potenciales clientes.
- Adaptar la experiencia a dispositivos móviles.

##  Solución propuesta

Se desarrolló una página web responsive con una estructura orientada a las necesidades de los clientes.
La página incluye:

- Presentación del negocio.
- Servicios de reparación, balanceo y alineación.
- Imágenes representativas de cada servicio.
- Horarios de atención.
- Ubicación mediante Google Maps.
- Información de contacto.
- Sistema de reseñas mediante un carrusel interactivo.

##  Tecnologías usadas

- Git

##  Funcionalidad

- Diseño responsive.
- Navegación mediante secciones.
- Servicios desplegables mediante JavaScript.
- Carrusel interactivo de reseñas.
- Cambio automático de reseñas.
- Botones de navegación entre reseñas.
- Animaciones y transiciones.
- Integración con Google Maps.
- Accesibilidad y navegación adaptable.
